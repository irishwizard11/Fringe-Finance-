# 🍀 Emerald Ledger (formerly Fringe Finance)

> **Empowering financial sovereignty and Bitcoin literacy across Ireland.**

**Emerald Ledger** is a bilingual (English & Gaeilge) educational application designed to bridge traditional financial literacy, sound money principles, and Bitcoin/blockchain fundamentals. 

Whether you're looking to understand budgeting basics or explore self-custody and digital assets, Emerald Ledger provides accessible, interactive learning paths tailored for Irish users.

---

## ✨ Key Features

- **🌐 Dual-Language Support:** Seamlessly switch between English and Gaeilge across all modules and interfaces.
- **📚 Interactive Learning Modules:** Step-by-step guides covering basic budgeting, inflation, sound money history, and Bitcoin technicals.
- **🧮 Interactive Financial Tools:** Built-in calculators for compound interest, dollar-cost averaging (DCA), and purchasing power inflation metrics over time.
- **🛡️ Self-Custody & Security Practice:** Interactive simulations helping users learn wallet management, seed phrase security, and key safety best practices without real financial risk.
- **🇮🇪 Localized Context:** Tailored insights covering Irish financial framework contexts, taxation basics, and local ecosystem resources.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** React / React Native (TypeScript)
- **State Management:** Zustand / React Context API
- **Styling:** Tailwind CSS / NativeWind
- **Internationalization (i18n):** `react-i18next` (English & Gaeilge bundles)
- **Build Tool:** Vite / Expo
